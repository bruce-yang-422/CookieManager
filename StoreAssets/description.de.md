# Chrome Web Store-Beschreibung — Deutsch

Version: v0.3.3

```text
Mit dem Cookie Manager können Sie Cookie nach Website organisieren, suchen, bearbeiten und exportieren und den Cache und die gespeicherten Daten einer Website löschen. Behandeln Sie die aktuelle Website über die Symbolleiste oder öffnen Sie das Dashboard, um Cookie für jede Website an einem Ort zu verwalten.

WEBSITE-KATEGORIEN UND VERWALTUNG
• Cookie werden nach Haupt-Website gruppiert, mit einer klaren Cookie-Anzahl für jede Website.
• Die automatische Kategorisierung erkennt gängige Dienste, Behörden-Domains und regionale Portale. Eigene Kategorien lassen sich mit individuellen Namen und Farben anlegen.
• Suche nach Website, Cookie-Name oder Domain.
• Löschen Sie ein einzelnes Cookie, eine ganze Website oder mehrere ausgewählte Websites gleichzeitig.

SCHNELLANSICHT UND BEARBEITUNG
• Wechseln Sie zwischen "Diese Seite" und "Ganze Website" in der Symbolleiste Popup.
• Erstellen oder Bearbeiten eines Cookie Name, Wert, Domain, Pfad und Ablauf.
• Passen Sie die Attribute Secure, HttpOnly und SameSite an.
• Kopieren Sie Wert, Name, name=value, JSON, Netscape oder den curl-Header eines Cookie.

CACHE UND WEBSITEDATEN LÖSCHEN
• Löschen Sie den Cache der aktuellen Website nur für diese Seite oder die gesamte Website und laden Sie die Seite automatisch neu.
• Löschen Sie über das Dashboard bestimmte Sites, löschen Sie ausgewählte Sites in großen Mengen oder löschen Sie alle Sites, während Sie die von Ihnen ausgewählten Sites beibehalten.
• Wählen Sie aus, welche Daten gelöscht werden sollen. Nur der Cache wird standardmäßig gelöscht, so dass Sie angemeldet bleiben.

WEBSITE-SPEICHER PRÜFEN
• Sehen Sie, wie viel Speicher die aktuelle Site in dem Symbolleisten-Popup verwendet.
• Anzeigen, Bearbeiten oder Löschen der Elemente, die eine Website in Ihrem Browser speichert.

IMPORT UND EXPORT
• Unterstützt JSON, Netscape (cookies.txt) und HTTP Cookie Header.
• Das Importformat wird automatisch erkannt; ältere Textkodierungen wie Big5, GB18030, Shift_JIS und Windows-1252 werden unterstützt.
• Exportieren Sie in eine Datei oder Kopie in die Zwischenablage für Website-Tests und andere Tools.
• Exportieren Sie die Site-Liste als CSV, JSON oder TXT.
• Importieren von Websitekategorien und Sichern und Wiederherstellen von Kategorieeinstellungen.

DATENZUGRIFF UND DATENSCHUTZ
• Um seine Funktionen bereitzustellen, liest und verarbeitet die Erweiterung lokal Cookie, die Anmeldeinformationen enthalten können.
• Es liest die URL des aktuellen Tabs, um die Cookie dieser Site anzuzeigen, und organisiert die Site-Liste nach Cookie-Domain. Wenn Sie Site-Daten löschen, liest es auch die URLs von offenen Tabs, um Subdomains zu finden, die mit ihm gelöscht werden sollen.
• Wenn Sie das Symbolleisten-Popup öffnen, liest es lokal die Daten, die die aktuelle Website in Ihrem Browser speichert, um die Nutzung anzuzeigen und sie verwalten zu lassen.
• Das Erstellen, Bearbeiten, Löschen, Löschen, Importieren und Exportieren von Cookie und Websitedaten erfolgt nur, wenn Sie sie starten.
• Kategorien, die Ausschlussliste und Präferenzen werden im Local Storage Ihres Browsers gespeichert.
• Der Entwickler erhält niemals Ihre Cookie, Anmeldeinformationen, Websitedaten oder Browserinformationen. Diese Daten werden niemals an einen externen Server gesendet, verkauft oder mit Dritten geteilt.
• Exportierte Daten werden nur auf Ihr Gerät heruntergeladen oder in Ihre Zwischenablage kopiert, wenn Sie danach fragen.
• Kein Konto erforderlich. Keine Werbung, Analysen, Tracker oder Remotecode.

BENUTZEROBERFLÄCHE
Erhältlich in traditionellem Chinesisch, vereinfachtem Chinesisch, Englisch, Japanisch, Deutsch, Koreanisch, Französisch, Russisch und Spanisch, mit dunklem Modus.

Für alle, die den Anmeldestatus überprüfen, die Cookie-Einstellungen testen, den Cache einer Website löschen müssen, um Ladeprobleme zu beheben, oder Browser-Cookie aufräumen.

Hinweis: Das Löschen oder Bearbeiten von Cookie oder das Löschen von Websitedaten kann Sie abmelden, Einstellungen zurücksetzen oder Offline-Daten entfernen. Exportierte Cookie können Anmeldeinformationen enthalten, also bewahren Sie sie auf und teilen Sie sie nicht.
```

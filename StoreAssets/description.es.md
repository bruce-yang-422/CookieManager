# Descripción de Chrome Web Store — Español

Versión: v0.3.0

```text
Cookie Manager le permite organizar, buscar, editar y exportar Cookie por sitio, y limpiar el caché de un sitio y los datos almacenados. Maneja el sitio actual de la barra de herramientas, o abre el panel para gestionar las Cookie de cada sitio en un mismo lugar.

CATEGORÍAS Y GESTIÓN DE SITIOS
• Las Cookie se agrupan por el sitio principal, con un recuento de Cookie claro para cada sitio.
• La clasificación automática reconoce servicios habituales, dominios gubernamentales y portales regionales. También puede crear categorías con sus propios nombres y colores.
• Búsqueda por sitio, nombre de Cookie o dominio.
• Eliminar una sola Cookie, un sitio completo o varios sitios seleccionados a la vez.

VISTA RÁPIDA Y EDICIÓN
• Interruptor entre "Esta página" y "sitio completo" en el popup de la barra de herramientas.
• Crear o editar el nombre, el valor, el dominio, la ruta y la expiración de una Cookie.
• Ajuste los atributos Secure, HttpOnly y SameSite.
• Copia el valor de una Cookie, nombre, nombre=valor, JSON, Netscape, o cabecera de curl.

BORRAR CACHÉ Y DATOS DEL SITIO
• Limpiar el caché del sitio actual, para esta página solamente o todo el sitio, y volver a cargar la página automáticamente.
• Desde el panel de control, sitios específicos claros, sitios seleccionados despejados a granel, o limpiar todos los sitios manteniendo los que elija.
• Elija qué datos despejar. Sólo el caché se aclara por defecto, por lo que se mantiene firmado.

REVISAR EL ALMACENAMIENTO DEL SITIO
• Vea cuánto almacenamiento utiliza el sitio actual en la barra de herramientas popup.
• Ver, editar o eliminar los elementos que un sitio almacena en su navegador.

IMPORTACIÓN Y EXPORTACIÓN
• Admite JSON, Netscape (cookies.txt) y HTTP Cookie Header.
• El formato de importación se detecta automáticamente y admite codificaciones antiguas como Big5, GB18030, Shift_JIS y Windows-1252.
• Exportar a un archivo o copiar al portapapeles para la prueba del sitio web y otras herramientas.
• Exportar la lista de sitios como CSV, JSON o TXT.
• Importar las categorías del sitio, y respaldar y restaurar la configuración de la categoría.

ACCESO A DATOS Y PRIVACIDAD
• Para proporcionar sus características, la extensión lee y procesa Cookie localmente, que puede incluir credenciales de inicio de sesión.
• Lee la URL de la pestaña actual para mostrar las Cookie de ese sitio y organiza la lista de sitios por dominio de Cookie. Cuando despeja los datos del sitio, también lee las URL de las pestañas abiertas para encontrar subdominios para aclarar junto con él.
• Cuando abre la barra de herramientas popup, localmente lee los datos que el sitio actual almacena en su navegador para mostrar el uso y le permite administrarlo.
• La creación, edición, eliminación, limpieza, importación y exportación de Cookie y datos del sitio solo ocurren cuando se inician.
• Categorías, la lista de exclusión y preferencias se almacenan en el Local Storage de su navegador.
• El desarrollador nunca recibe sus Cookie, credenciales de inicio de sesión, datos del sitio o información de navegación. Estos datos nunca se envían a un servidor externo, vendido o compartido con terceros.
• Los datos exportados solo se descargan en el dispositivo o se copian en el portapapeles cuando se lo pida.
• No se requiere cuenta. No hay anuncios, análisis, rastreadores o código remoto.

INTERFAZ
Disponible en chino tradicional, chino simplificado, inglés, japonés, alemán, coreano, francés, ruso y español, con modo oscuro.

Para cualquier persona que necesite comprobar estado de inicio de sesión, probar la configuración de Cookie, limpiar el caché de un sitio para solucionar problemas de carga, o ordenar las Cookie del navegador.

Nota: Eliminar o editar Cookie, o borrar datos del sitio, puede firmar, restablecer preferencias o eliminar datos fuera de línea. Las Cookie exportadas pueden contener credenciales de inicio de sesión, así que manténganlas seguras y no las compartan.

Sitio web: https://cookie-manager.stack-base.com/
Política de privacidad: https://cookie-manager.stack-base.com/privacy.html
```

# Chrome Web Store 商品说明 — 简体中文

适用版本：v0.3.3

```text
Cookie Manager 让你依网站整理、搜寻、编辑与导出 Cookie，也能清除网站的缓存与储存数据。从工具栏快速处理目前网站，或打开管理后台，集中管理所有网站的 Cookie。

【网站分类与管理】
• 依主网站整合 Cookie，清楚查看各网站的 Cookie 数量。
• 自动分类可识别常用服务、政府域名与各地区门户网站，也能新增分类、自定义名称与颜色。
• 搜寻网站、Cookie 名称或域名。
• 删除单一 Cookie、整个网站，或勾选多个网站批次处理。

【快速查看与编辑】
• 在工具栏窗口切换「此页面」与「整个网站」范围。
• 新增或编辑 Cookie 的名称、值、域名、路径与到期时间。
• 调整 Secure、HttpOnly、SameSite 等属性。
• 复制 Cookie 值、名称、name=value、JSON、Netscape 或 curl 标头。

【清除缓存与网站数据】
• 清除目前网站的缓存，可选择只清此页面或整个网站，并在清除后自动重新载入页面。
• 在管理后台清除指定网站、勾选多个网站批次清除，或一次清除所有网站并保留你指定的网站。
• 可自行选择要清除哪些数据；默认只清除缓存，不会让网站退出登录。

【检视网站储存空间】
• 在工具栏窗口查看目前网站使用了多少储存空间。
• 检视、编辑或删除网站储存在浏览器中的项目。

【导入与导出】
• 支援 JSON、Netscape（cookies.txt）与 HTTP Cookie Header。
• 导入时自动判断格式，并支持 Big5、GB18030、Shift_JIS 与 Windows-1252 等旧版文本编码。
• 导出文件或复制到剪贴板，方便网站测试及工具使用。
• 导出网站清单为 CSV、JSON 或 TXT。
• 导入网站分类，备份与还原分类设置。

【数据存取与隐私】
• 为提供管理功能，扩充功能会在本地读取及处理 Cookie，其中可能包含登录凭证。
• 读取目前分页网址，以显示该网站的 Cookie；依 Cookie 域名整理网站清单。清除网站数据时，也会读取开启中分页的网址，以找出要一并清除的子域名。
• 开启工具栏窗口时，会在本地读取目前网站储存在浏览器中的数据，以显示用量并供使用者管理。
• Cookie 与网站数据的新增、修改、删除、清除、导入与导出由使用者主动操作。
• 分类、排除清单与偏好设置储存在浏览器本地空间。
• 开发者不会接收 Cookie、登录凭证、网站数据或网站资讯；这些数据不会传送至外部服务器，也不会出售或分享给第三方。
• 导出数据仅依使用者操作下载至装置或复制到剪贴板。
• 不需要帐号，不含广告、分析追踪工具或远端程式码。

【介面】
支援繁体中文、简体中文、英文、日本语、Deutsch、한국어、Français、Русский、Español，以及深色模式。

适合需要检查网站登录状态、测试 Cookie 设置、清除网站缓存以排除载入问题，或整理浏览器 Cookie 的使用者。

提醒：删除或修改 Cookie、清除网站数据，可能使网站退出登录、重设偏好或遗失离线数据。导出的 Cookie 可能包含登录凭证，请妥善保管，避免分享给他人。

官方网站：https://cookie-manager.stack-base.com/
隐私权政策：https://cookie-manager.stack-base.com/privacy.html
```

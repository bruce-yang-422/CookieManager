# Chrome Web Store 설명 — 한국어

대상 버전: v0.3.0

```text
Cookie Manager는 사이트로 구성, 검색, 편집 및 수출 Cookie를 정리하고 사이트 캐시 및 저장된 데이터를 삭제합니다. 도구 모음에서 현재 사이트를 처리하거나 대시보드를 열고 각 사이트에 대한 Cookie를 관리합니다.

사이트 카테고리 및 관리
• Cookie는 각 사이트에 대한 명확한 Cookie 수와 함께 메인 사이트에 의해 그룹화됩니다.
• 자동 분류로 일반 서비스, 정부 도메인 및 지역별 포털 사이트를 인식하며, 원하는 이름과 색상으로 사용자 지정 카테고리를 만들 수 있습니다.
• 사이트, Cookie 이름, 또는 도메인에 의해 검색.
• 단일 Cookie, 전체 사이트 또는 한 번에 여러 선택된 사이트를 삭제합니다.

빠른 확인 및 편집
• 도구 모음 팝업의 "이 페이지"와 "전체 사이트"범위를 전환합니다.
• Cookie의 이름, 값, 도메인, 경로 및 만료를 만들거나 편집합니다.
• Secure, HttpOnly 및 SameSite 속성을 조정합니다.
• Cookie의 값, 이름, name=value, JSON, Netscape 또는 curl 헤더를 복사합니다.

캐시 및 사이트 데이터 삭제
• 현재 사이트 캐시를 정리, 이 페이지에 대한 또는 전체 사이트, 그리고 페이지를 자동으로 다시로드.
• 대시보드에서, 명확한 특정한 위치, 대량에 있는 명확한 선정한 위치, 또는 당신이 선택하는 것을 지키는 동안 모든 위치를 삭제하십시오.
• 어떤 데이터를 명확하게 선택하십시오. 캐시는 기본적으로 명확하므로 로그인해야 합니다.

사이트 저장 공간 확인
• 도구 모음 팝업에서 현재 사이트 사용량을 저장하는 방법을 참조하십시오.
• 브라우저에서 사이트 매장을 삭제, 편집, 삭제합니다.

가져오기 및 내보내기
• JSON, Netscape (cookies.txt) 및 HTTP Cookie Header를 지원합니다.
• 가져오기 형식을 자동으로 감지하며 Big5, GB18030, Shift_JIS 및 Windows-1252 같은 기존 문자 인코딩을 지원합니다.
• 파일로 내보내거나 웹 사이트 테스트 및 기타 도구에 클립보드에 복사하십시오.
• CSV, JSON 또는 TXT로 사이트 목록 내보내기.
• 사이트 범주를 가져 오기 및 백업 및 범주 설정을 복원합니다.

데이터 접근 및 개인정보 보호
• 이 기능을 제공하기 위해, 확장은 로그인 자격 증명을 포함 할 수있는 Cookie를 로컬로 읽고 프로세스.
• 현재 탭의 URL을 읽어 사이트의 Cookie를 표시하고, Cookie 도메인에 의해 사이트 목록을 구성합니다. 사이트 데이터를 삭제할 때, 하위 도메인을 발견하기 위해 열린 탭의 URL을 읽습니다.
• 도구 모음 팝업을 열면 브라우저의 현재 사이트 저장소를 로컬로 읽습니다. 사용량을 표시하고 관리할 수 있습니다.
• 생성, 편집, 삭제, 취소, 수입 및 수출 Cookie 및 사이트 데이터는 당신이 시작할 때만 발생합니다.
• 카테고리, 제외 목록 및 환경설정은 브라우저의 Local Storage에 저장됩니다.
• 개발자는 Cookie, 로그인 자격, 사이트 데이터, 또는 검색 정보를 수신하지 않습니다. 이 데이터는 외부 서버, 판매 또는 제삼자와 공유하지 않습니다.
• 수출된 자료는 당신의 장치에 다운로드되거나 당신이 요구할 때 클립보드에 복사됩니다.
• 계정 없음. 광고, 분석, 추적기, 또는 원격 코드 없음.

인터페이스
중국어 번체, 중국어 간체, 영어, 일본어, 독일어, 한국어, 프랑스어, 러시아어, 스페인어, 어두운 모드로 사용할 수 있습니다.

로그인 상태, 테스트 Cookie 설정, 로드 문제를 해결하기 위해 사이트의 캐시를 삭제하거나 브라우저 Cookie를 tidy.

참고: Cookie를 삭제하거나 편집하거나, 사이트 데이터를 삭제하거나, 설정을 재설정하거나 오프라인 데이터를 제거할 수 있습니다. 수출 된 Cookie는 로그인 자격 증명을 포함 할 수 있으므로 안전하고 공유하지 마십시오.

개인정보 보호정책: https://cookie-manager.stack-base.com/privacy.html
```

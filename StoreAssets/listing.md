# Chrome 線上應用程式商店：產品詳細資料

適用版本：v0.3.1（以 v0.1.0 上架時的說明為基礎更新）

- **名稱**與**摘要**取自套件內的 `public/_locales/*/messages.json`，上傳新套件後自動更新，不需在資訊主頁手動修改。
- **說明**欄位只接受純文字（上限 16,000 字元），請複製下方程式碼區塊內的文字貼上。

## 繁體中文（zh_TW）

```text
Cookie Manager 讓你依網站整理、搜尋、編輯與匯出 Cookie，也能清除網站的快取與儲存資料。從工具列快速處理目前網站，或打開管理後台，集中管理所有網站的 Cookie。

【網站分類與管理】
• 依主網站整合 Cookie，清楚查看各網站的 Cookie 數量。
• 自動分類可辨識常用服務、政府網域與各地入口網站，也能新增分類、自訂名稱與顏色。
• 搜尋網站、Cookie 名稱或網域。
• 刪除單一 Cookie、整個網站，或勾選多個網站批次處理。

【快速查看與編輯】
• 在工具列視窗切換「此頁面」與「整個網站」範圍。
• 新增或編輯 Cookie 的名稱、值、網域、路徑與到期時間。
• 調整 Secure、HttpOnly、SameSite 等屬性。
• 複製 Cookie 值、名稱、name=value、JSON、Netscape 或 curl 標頭。

【清除快取與網站資料】
• 清除目前網站的快取，可選擇只清此頁面或整個網站，並在清除後自動重新載入頁面。
• 在管理後台清除指定網站、勾選多個網站批次清除，或一次清除所有網站並保留你指定的網站。
• 可自行選擇要清除哪些資料；預設只清除快取，不會讓網站登出。

【檢視網站儲存空間】
• 在工具列視窗查看目前網站使用了多少儲存空間。
• 檢視、編輯或刪除網站儲存在瀏覽器中的項目。

【匯入與匯出】
• 支援 JSON、Netscape（cookies.txt）與 HTTP Cookie Header。
• 匯入時自動判斷格式，並支援 Big5、GB18030、Shift_JIS 與 Windows-1252 等舊式文字編碼。
• 匯出檔案或複製到剪貼簿，方便網站測試及工具使用。
• 匯出網站清單為 CSV、JSON 或 TXT。
• 匯入網站分類，備份與還原分類設定。

【資料存取與隱私】
• 為提供管理功能，擴充功能會在本機讀取及處理 Cookie，其中可能包含登入憑證。
• 讀取目前分頁網址，以顯示該網站的 Cookie；依 Cookie 網域整理網站清單。清除網站資料時，也會讀取開啟中分頁的網址，以找出要一併清除的子網域。
• 開啟工具列視窗時，會在本機讀取目前網站儲存在瀏覽器中的資料，以顯示用量並供使用者管理。
• Cookie 與網站資料的新增、修改、刪除、清除、匯入與匯出由使用者主動操作。
• 分類、排除清單與偏好設定儲存在瀏覽器本機空間。
• 開發者不會接收 Cookie、登入憑證、網站資料或網站資訊；這些資料不會傳送至外部伺服器，也不會出售或分享給第三方。
• 匯出資料僅依使用者操作下載至裝置或複製到剪貼簿。
• 不需要帳號，不含廣告、分析追蹤工具或遠端程式碼。

【介面】
支援繁體中文、简体中文、英文、日本語、Deutsch、한국어、Français、Русский、Español，以及深色模式。

適合需要檢查網站登入狀態、測試 Cookie 設定、清除網站快取以排除載入問題，或整理瀏覽器 Cookie 的使用者。

提醒：刪除或修改 Cookie、清除網站資料，可能使網站登出、重設偏好或遺失離線資料。匯出的 Cookie 可能包含登入憑證，請妥善保管，避免分享給他人。

官方網站：https://cookie-manager.stack-base.com/
隱私權政策：https://cookie-manager.stack-base.com/privacy.html
```

## 日本語（ja）

```text
Cookie Manager は、Cookie をサイトごとに整理・検索・編集・エクスポートでき、サイトのキャッシュや保存データも削除できる拡張機能です。ツールバーから現在のサイトをすばやく操作したり、管理画面ですべてのサイトの Cookie をまとめて管理したりできます。

【サイトの分類と管理】
• Cookie をメインサイトごとにまとめ、サイトごとの Cookie 数をひと目で確認できます。
• 一般的なサービス、政府ドメイン、各地域のポータルサイトを自動分類できます。分類の追加や名前・色のカスタマイズにも対応しています。
• サイト、Cookie 名、ドメインで検索できます。
• Cookie 1 件、サイト全体、または選択した複数のサイトを一括で削除できます。

【すばやい確認と編集】
• ツールバーのポップアップで「このページ」と「サイト全体」を切り替えられます。
• Cookie の名前、値、ドメイン、パス、有効期限を作成・編集できます。
• Secure、HttpOnly、SameSite などの属性を調整できます。
• Cookie の値、名前、name=value、JSON、Netscape、curl ヘッダーをコピーできます。

【キャッシュとサイトデータの削除】
• 現在のサイトのキャッシュを削除できます。このページのみ、またはサイト全体を選択でき、削除後にページを自動で再読み込みします。
• 管理画面から、指定したサイトの削除、選択した複数サイトの一括削除、または残したいサイトを除いた全サイトの削除ができます。
• 削除するデータは自由に選べます。初期設定ではキャッシュのみを削除するため、ログアウトしません。

【サイトのストレージを確認】
• ツールバーのポップアップで、現在のサイトが使用しているストレージ容量を確認できます。
• サイトがブラウザーに保存している項目を表示・編集・削除できます。

【インポートとエクスポート】
• JSON、Netscape（cookies.txt）、HTTP Cookie ヘッダーに対応しています。
• インポート時に形式を自動判別し、Big5、GB18030、Shift_JIS、Windows-1252 などの従来の文字コードにも対応します。
• ファイルへのエクスポートやクリップボードへのコピーで、サイトのテストやツールに活用できます。
• サイト一覧を CSV、JSON、TXT でエクスポートできます。
• サイト分類のインポート、分類設定のバックアップと復元ができます。

【データへのアクセスとプライバシー】
• 管理機能を提供するため、拡張機能は Cookie を端末内で読み取り・処理します。Cookie にはログイン情報が含まれる場合があります。
• 現在のタブの URL を読み取ってそのサイトの Cookie を表示し、Cookie のドメインをもとにサイト一覧を整理します。サイトデータを削除するときは、一緒に削除するサブドメインを見つけるために、開いているタブの URL も読み取ります。
• ツールバーのポップアップを開いたときに、現在のサイトがブラウザーに保存しているデータを端末内で読み取り、使用量の表示と管理に使用します。
• Cookie とサイトデータの作成・編集・削除・消去・インポート・エクスポートは、ユーザーが操作したときにのみ行います。

• アカウント不要。広告、分析・トラッキングツール、リモートコードは含まれていません。
```

## 隱私權實務（開發人員資訊主頁 > 隱私權）

以 v0.1.0 審查通過的內容為基礎，配合 v0.2.0 新增的 `browsingData`、`scripting` 權限更新。

### 單一用途說明

```text
讓使用者依網站管理瀏覽器為各網站儲存的資料，包括 Cookie 與網站儲存空間（快取、Local Storage、IndexedDB 等）：查看、搜尋、分類、新增、編輯、刪除、清除及匯入匯出。工具列視窗用於目前網站，管理後台則提供跨網站整理與批次操作；所有功能皆服務於網站資料管理，資料處理於使用者本機完成。
```

### 要求 cookies 的理由

```text
此權限是 Cookie 管理的核心功能所必需。擴充功能透過 chrome.cookies API 讀取 Cookie 以顯示、搜尋及依網站整理，並依使用者操作新增、修改、刪除或匯入 Cookie；同時監聽 Cookie 變更以更新列表，並依 Cookie 網域找出網站的子網域，作為清除網站資料的範圍。Cookie 內容不會傳送至外部伺服器。
```

### 要求 storage 的理由

```text
使用 chrome.storage.local 儲存使用者建立的分類名稱、顏色、排列順序、網站分類對應、自動分類設定及資料版本，以及清除網站資料時選擇的資料類型、時間範圍與排除清單，並同步擴充功能不同頁面的設定。這些資料僅儲存在本機，不使用雲端同步，也不會傳送至外部伺服器。
```

### 要求 favicon 的理由（不變）

```text
透過 Chrome 內建的 favicon API，在網站清單及 Cookie 管理介面顯示對應的網站圖示，協助使用者辨識不同網站。使用瀏覽器提供的圖示來源，不透過第三方圖示服務查詢。
```

### 要求 browsingData 的理由

```text
用於「清除網站資料」功能。使用者在工具列視窗或管理後台選擇網站與資料類型（HTTP 快取、Cache Storage、Service Worker、Local Storage、IndexedDB、檔案系統與 WebSQL、Cookie）並按下清除後，擴充功能透過 chrome.browsingData.remove 依來源（origins）清除這些網站的資料；清除所有網站時，可用排除清單（excludeOrigins）保留使用者指定的網站。只在使用者主動操作時執行，不會自動或定期清除，也不讀取或清除瀏覽紀錄、下載紀錄、密碼或表單資料。
```

### 要求 scripting 的理由

```text
用於在工具列視窗顯示與管理目前網站的儲存空間。使用者開啟工具列視窗時，擴充功能透過 chrome.scripting.executeScript 在目前分頁執行擴充功能內建的函式，讀取該網站的 Local Storage 與 Session Storage 項目、IndexedDB 資料庫名稱、Cache Storage 名稱與項目數、Service Worker 範圍及儲存空間用量；使用者操作時，再執行編輯或刪除項目、刪除資料庫或快取、取消註冊 Service Worker。只作用於目前分頁的頂層頁面，不讀取網頁 DOM 內容，不宣告常駐內容腳本，不載入遠端程式碼；資料僅在本機處理，不傳送至外部伺服器。
```

### 要求網站存取權限的理由

```text
Cookie Manager 的單一用途是讓使用者管理任意網站在瀏覽器中儲存的資料（Cookie 與網站儲存空間）。管理後台需要列出不同網站的 Cookie，提供跨網站搜尋、分類、匯出、批次刪除與清除網站資料；工具列視窗則管理目前網站的 Cookie 與儲存空間。

這些功能需要 cookies 權限及對應網站的主機存取權限；在目前分頁使用 scripting 讀取與管理 Local Storage、IndexedDB 等儲存空間，也需要該網站的主機存取權限。清除網站資料時，也會讀取開啟中分頁的網址，以找出要一併清除的子網域。由於管理範圍由使用者決定，無法預先限定網站清單，因此使用 <all_urls>。僅存取目前分頁的 activeTab 無法滿足跨網站管理需求。

擴充功能不宣告常駐內容腳本，也不讀取網頁 DOM；只在使用者開啟工具列視窗或進行操作時，於目前分頁執行擴充功能內建的函式來讀取與管理儲存空間。Cookie 與網站資料僅在本機處理，不傳送至外部伺服器；修改、刪除、清除及匯出均由使用者主動操作。
```
